# 🧠 Rumour Detection System

A Streamlit-based web app that detects whether a news headline, article text, or URL is **Real or Fake** using Machine Learning + Live News Evidence.

---

## 🚀 Features

* Analyze Headlines, Text, and URLs
* ML Model (TF-IDF + Logistic Regression)
* Google News + Trusted RSS Verification
* Voice Input Support
* Evidence-based Result

---

## ⚙️ Run Locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

---

## 🛠 Tech Stack

* Python
* Streamlit
* Scikit-learn
* Newspaper3k
